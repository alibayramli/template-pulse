# Template Pulse Node utilities

Backend helpers for filters, permissions, statistics, run history, and teams. Requires Node.js 22 or 24.

Installed automatically with the backend. Add it directly only if your code imports it:

```sh
yarn workspace backend add @abayramli/backstage-plugin-template-pulse-node
```

Exports `aggregateExecutions`, `parseExecutionQuery`, `parseExecutionFacetQuery`, `authorizeExecutionQuery`, `HistoryClient`, and `TeamMembersClient`.

[Installation guide](https://github.com/alibayramli/template-pulse#add-to-backstage)
